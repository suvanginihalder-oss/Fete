================================================================================
PART 1: CHANGES / UPDATES MADE IN THE DEPLOYED VERSION
================================================================================

1. Parallel Sectioned GenAI Architecture (Solving Serverless Timeouts):
   - Replaced traditional monolithic "one-shot" plan generation with 4 concurrent, 
     parallel API calls (Concept, Budget, Timeline & Schedule, Vendors & Plan B).
   - Prevents Vercel serverless function timeouts (10s hobby limit) and reduces 
     total generation latency by ~70%.
   - Implemented progressive skeleton loading so each section renders independently 
     as soon as its stream arrives, accompanied by automatic single-retry error guards.

2. Code-Owned Financial & Temporal Mathematics (Zero Hallucination Guarantee):
   - Eliminated LLM calculation errors: code (not the AI) strictly governs all 
     financial math via deterministic TypeScript functions (src/lib/math.ts).
   - Budget lines are dynamically rescaled to match the target total down to the exact 
     penny/rupee, eliminating rounding loss.
   - Built a real-time "What-If" Budget Simulation Slider that rescales allocations 
     and recalculates per-head costs entirely client-side without costly AI calls.
   - Converts offset days into real calendar dates; automatically detects tight 
     event timelines and compresses milestone intervals while flagging overdue tasks.
   - Fully covered with 8 automated unit tests running on Vitest.

3. Context-Aware AI Chat Assistant with 1-Click Structured Diffs:
   - Built an interactive chat assistant with full context of the active event plan 
     (budget, timeline, guests, city, dietary constraints).
   - Returns structured diff cards (e.g., reallocating catering savings to the emergency 
     buffer or inserting a weather contingency task) that users can review and apply 
     with a single click, instantly re-running all financial and date formulas.

4. Guest Roster & RSVP Costing Engine:
   - Added interactive guest tracking (status: confirmed, pending, declined) with 
     plus-one headcount computations.
   - Computes dynamic per-head costs (Total Budget / Effective Headcount) and produces 
     an aggregated dietary restriction tally (Pure Veg, Jain, Halal, etc.) for catering teams.

5. Multi-Tone Invitation Suite & Zero-Backend Sharing:
   - Added an AI Invitation Generator producing customized invitation copy in 4 distinct 
     tones (Formal, Casual, Poetic, Funky) with 1-click WhatsApp dispatch links.
   - Implemented zero-backend URL sharing using lz-string URI compression. Encodes the entire 
     event blueprint into the browser URL, allowing instant read-only sharing without 
     requiring user logins or external database servers.
   - Added JSON backup export/import and dedicated print/PDF stylesheets (@media print).

6. Demo Safety Guard & Rate Limiting:
   - Implemented per-IP rate limiting and daily request quotas.
   - If API limits, rate caps, or network outages occur, CelebrAI automatically falls back 
     to a high-fidelity local demo generator with an honest banner: "Sample plan, not live AI", 
     ensuring the demo never crashes during evaluation or live judging.
   - Pre-seeded with a 1-click sample: "Aura '26: Inter-College Cultural & Arts Fest" 
     (250 guests, ₹50,000, 1 month away).


================================================================================
PART 2: GEN AI SERVICES UTILIZED IN THE SUBMISSION & WHERE THEY ARE UTILIZED
================================================================================

1. Primary GenAI Service:
   - Google Gemini API (Model: gemini-1.5-flash via Google AI Studio Developer API)
   - Reason: Ultra-low latency, generous free tier rate limits, and native structured 
     JSON mode output.

2. Provider Adapter Architecture (Multi-Model Support):
   - Implemented in a unified adapter file (src/lib/ai/providerAdapter.ts).
   - Allows seamless runtime switching between:
     * Google Gemini API (gemini-1.5-flash) [Default / Free Tier]
     * Anthropic Claude API (claude-3-haiku-20240307)
     * OpenAI API (gpt-4o-mini)
     Controlled via the LLM_PROVIDER environment variable.

3. Specific Locations Where GenAI is Utilized:

   A. Section A: Creative Concept & Theming Engine
      - Endpoint: POST /api/generate-plan (section: "concept")
      - Location in Code: src/lib/ai/parallelPlanner.ts, api/generate-plan.ts
      - What it does: Ingests event type, city, theme, cultural background, dietary 
        requirements, and special constraints to generate:
        * Creative thematic tagline
        * Mood, decor styling, and percentage budget shares
        * Signature culinary menu highlights tailored to dietary needs
        * Staged entertainment lineups (acoustic -> mainstage -> DJ/finale)
        * Interactive crowd engagement and memory activities.

   B. Section B: Intelligent Budget Allocation & Savings Engine
      - Endpoint: POST /api/generate-plan (section: "budget")
      - Location in Code: src/lib/ai/parallelPlanner.ts, api/generate-plan.ts
      - What it does: Analyzes event requirements to recommend tailored category 
        allocation weights (Venue, Catering, Decor, Production, Buffer). Crucially, 
        it identifies high-impact "Cheaper Alternatives" with estimated savings amounts 
        (e.g., student guild fabrication, seasonal blooms) that users can adopt with 1 click.

   C. Section C: Milestones Timeline & Minute-by-Minute Run Sheet Engine
      - Endpoint: POST /api/generate-plan (section: "timeline")
      - Location in Code: src/lib/ai/parallelPlanner.ts, api/generate-plan.ts
      - What it does: Generates logical event preparation milestones with priority 
        and dueOffsetDays relative to the event date. Additionally generates a complete 
        minute-by-minute event-day schedule specifying time slots, activities, team 
        owners (e.g. Stage Lead, Hospitality Desk), and operational cues.

   D. Section D: Vendor Intelligence, Checklist & Risk Management Engine
      - Endpoint: POST /api/generate-plan (section: "vendors")
      - Location in Code: src/lib/ai/parallelPlanner.ts, api/generate-plan.ts
      - What it does: Generates objective vendor categories with estimated market cost 
        ranges, critical vendor negotiation questions, coordinator field tips, and an 
        unpredictable weather Plan B (contingency steps, standby gear, indoor transitions).

   E. Context-Aware Event Planning Chat Assistant
      - Endpoint: POST /api/chat
      - Location in Code: api/chat.ts, src/components/ChatAssistantDrawer.tsx
      - What it does: Ingests the full live blueprint context (name, city, guests, budget, 
        current allocations, timeline). Responds to host inquiries and returns structured 
        executable diff proposals (e.g., "Reduce food & decor by ₹8,000 to boost emergency buffer") 
        which the user can apply directly to mutate the live state.

   F. Contextual Multi-Tone Invitation Generator
      - Location in Code: src/lib/sharing.ts, src/components/tabs/InvitationsTab.tsx
      - What it does: Synthesizes the event's theme, date, city, and host preferences to 
        craft customized invitation text across 4 distinct communication styles:
        * Formal (ceremonial & polite)
        * Casual (approachable & friendly)
        * Poetic (nostalgic & evocative)
        * Funky (high-energy & celebratory)
        Formatted with direct 1-click WhatsApp messaging URL links.
