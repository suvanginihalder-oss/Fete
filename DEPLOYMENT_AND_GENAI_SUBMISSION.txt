================================================================================
QUESTION 1: DESCRIBE THE CHANGES/UPDATES MADE IN THE DEPLOYED VERSION
================================================================================

The deployed version of CelebrAI introduces key full-stack and architectural advancements that transform traditional event planning into an intelligent, resilient, and demo-safe production application:

1. Parallel Sectioned GenAI Generation:
   To overcome the 10-second timeout limitation of serverless environments (Vercel), monolithic plan generation was replaced with 4 concurrent, asynchronous streams:
   - Section A: Creative Concept & Theming
   - Section B: Itemized Budget & Cost-Saving Options
   - Section C: Preparation Timeline & Minute-by-Minute Run Sheet
   - Section D: Vendor Negotiation Checklist & Weather Contingency Plan B
   This parallel execution reduces total wait time by ~70%. Each section validates against strict Zod schemas and renders progressively with skeleton loaders, supported by automated single-retry error recovery.

2. Code-Owned Financial & Temporal Mathematics (Zero Hallucination):
   Language models frequently make rounding and arithmetic errors. CelebrAI completely decouples math from the LLM:
   - Integer Rescaling: Budget allocations are mathematically rescaled down to the exact rupee/cent, eliminating penny discrepancies.
   - Interactive What-If Slider: Users can adjust total budget or guest headcount in real time; all allocations, per-head costs, and warnings re-calculate instantly in code without triggering any API calls.
   - Intelligent Date Calculation: Converts preparation offset days into real calendar dates. If an event date is close, the engine automatically compresses milestone intervals and highlights unavoidable overdue milestones.
   - Verified by 8 automated Vitest unit tests covering budget distribution, date parsing, and RSVP metrics.

3. Context-Aware AI Chat Assistant with 1-Click Actionable Diffs:
   Built a conversational assistant that retains full blueprint context (budget, dates, guests, dietary constraints). Instead of generic advice, it outputs structured diff proposals (e.g., shifting ₹8,000 from floral decor into an emergency buffer). Users apply changes with a single click, automatically executing code math recalculations.

4. Guest Management & Dynamic RSVP Costing:
   Integrated a full guest tracker managing invitation statuses (confirmed, pending, declined) and plus-ones. It computes dynamic per-head spend (Total Budget / Attending Headcount) and compiles aggregated dietary summaries (Pure Veg, Jain, Gluten-Free) for catering vendors.

5. Multi-Tone Invitations & Zero-Backend URL Sharing:
   - AI Invitation Studio crafts customized invites across 4 distinct tones (Formal, Casual, Poetic, Funky) with direct 1-click WhatsApp messaging links.
   - Zero-Backend URL Sharing: Encodes the full event state into a compressed URL hash via lz-string, allowing instant, authenticated-free, read-only link sharing without a database or server dependency.
   - Includes JSON backup export/import and dedicated print/PDF styling (@media print).

6. Demo Safety Guard & Rate Limiting:
   Enforced per-IP rate limiting and automated fallback to an offline high-fidelity sample engine when quotas or outages hit. A transparent banner notifies users: "Sample plan, not live AI (Demo Safety Active)", ensuring evaluations and live demos never crash.


================================================================================
QUESTION 2: MENTION THE GEN AI SERVICES UTILIZED IN THE SUBMISSION, AND WHERE DID YOU UTILIZE IT?
================================================================================

1. Primary GenAI Service & Foundation Model:
   - Service: Google Gemini API (Model: gemini-1.5-flash via Google AI Studio Developer API).
   - Selection Rationale: Offers low latency, native structured JSON output formatting, and generous free-tier rate limits ideal for high-throughput parallel section calls.

2. Provider Adapter Architecture (Multi-Model Portability):
   Implemented in a modular adapter pattern (src/lib/ai/providerAdapter.ts) allowing instant switching between:
   - Google Gemini API (gemini-1.5-flash) [Default]
   - Anthropic Claude API (claude-3-haiku-20240307)
   - OpenAI API (gpt-4o-mini)
   Switchable in production via the LLM_PROVIDER environment variable.

3. Specific Locations Where GenAI is Utilized:

   A. Creative Concept & Theming Engine
      - Endpoint & Files: POST /api/generate-plan (section: "concept") | src/lib/ai/parallelPlanner.ts
      - Application: Synthesizes event type, venue city, guest count, cultural traditions, and dietary requirements to generate bespoke taglines, theme styling, budget percentage shares, signature multi-course culinary highlights, staged entertainment schedules, and crowd engagement activities.

   B. Budget Allocation & Cost-Optimization Engine
      - Endpoint & Files: POST /api/generate-plan (section: "budget") | src/lib/ai/parallelPlanner.ts
      - Application: Evaluates local city pricing and event category norms to establish baseline expenditure weights. It identifies pragmatic "Cheaper Alternatives" with estimated monetary savings (e.g., sourcing alumni artists, utilizing in-house venue sound rigs) that can be applied with one click.

   C. Milestone Timeline & Minute-by-Minute Run Sheet Engine
      - Endpoint & Files: POST /api/generate-plan (section: "timeline") | src/lib/ai/parallelPlanner.ts
      - Application: Calculates chronological preparation intervals (dueOffsetDays) categorized by priority. Also produces an event-day minute-by-minute operational run sheet with specific time windows, activity milestones, and lead team assignments (e.g., Stage Lead, Hospitality Captain).

   D. Vendor Intelligence & Risk Contingency Engine
      - Endpoint & Files: POST /api/generate-plan (section: "vendors") | src/lib/ai/parallelPlanner.ts
      - Application: Produces realistic vendor categories with objective market price ranges, hard-hitting negotiation questions to prevent hidden fees, expert coordinator field advice, and a comprehensive Weather Plan B (risk assessment, contingency steps, standby equipment).

   E. Context-Aware Assistant with Structured Diffs
      - Endpoint & Files: POST /api/chat | api/chat.ts, src/components/ChatAssistantDrawer.tsx
      - Application: Takes the full live event state as prompt context. When asked to optimize expenses or adjust logistics, it generates structured payload diffs that modify lines and timeline milestones directly in the user's active session.

   F. Contextual Multi-Tone Invitation Generator
      - Files: src/lib/sharing.ts | src/components/tabs/InvitationsTab.tsx
      - Application: Transforms event theme, venue, date, and host constraints into tailored invitation copy across Formal, Casual, Poetic, and Funky tones with direct WhatsApp dispatch integration.
